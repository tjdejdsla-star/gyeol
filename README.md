# 결 (Gyeol) — 움직임 반응형 미디어아트 웹앱

카메라 앞의 움직임을 데이터(움직임 에너지·방향·사람 실루엣)로 바꿔, 그 데이터로 화면의 **도형·점·기호·활자**를 변형시키는 전시용 웹앱입니다.
파일 하나(`index.html`)로 동작하고, 카메라 영상은 기기 밖으로 나가지 않습니다.

## 모드 (키보드 1~8, 화면에서 좌우 스와이프)

| 키 | 이름 | 느낌 |
|---|---|---|
| 1 | 도형 | 격자 위 기본 도형(원·사각형)이 사람이 있는 곳에서 커지고, 움직임 방향으로 밀리고 늘어나고 회전 |
| 2 | 점 | 흩어진 점들이 사람에게 모여들어 실루엣을 만들고, 사람이 움직이면 따라가며 흩어졌다 다시 모임 |
| 3 | 기호 | 빨강·파랑 ▲●로 실루엣을 만들고, 움직이는 부분은 방향 화살표로 바뀜 (잔상 남음) |
| 4 | 활자 | 큰 글자 커튼. 움직임이 글자 줄을 잡아당기고, 사람은 검은 실루엣으로 올라감 (문장은 설정에서 수정) |
| 5 | 흐름 | 움직임을 따라 흐르는 입자 |
| 6 | 번짐 | 실루엣이 먹처럼 번지고, 움직임이 그림을 끌고 감 |
| 7 | 물결 | 움직임이 수면에 파문을 남김 |
| 8 | 잔상 | 지나간 실루엣이 색층으로 남음 |

팔레트 6종(흰/밤/먹/네온/노을/바다): 하단 색 점 또는 `P` 키, 위아래 스와이프.

## 실행 방법 세 가지

### A. 노트북·태블릿 한 대로 (가장 간단)
1. `index.html`을 Chrome(또는 Edge)에서 열기 — 더블클릭으로 열어도 카메라가 됩니다.
2. **이 기기로 바로 시작** → 카메라 허용.
3. `F` 전체화면, `H` 메뉴 숨기기. 메뉴는 4초 뒤 자동으로 사라지고, 화면을 건드리면 다시 나옵니다.

### B. 아이폰·아이패드로 (HTTPS 주소 필요)
iOS Safari는 `https://` 주소에서만 카메라를 켜 줍니다. 파일을 한 번만 올려두면 됩니다.

- **GitHub Pages**: 새 저장소 → `index.html` 업로드 → Settings → Pages → Branch: main → 저장. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열림.
- **Netlify Drop**: https://app.netlify.com/drop 에 `index.html`이 든 폴더를 끌어다 놓으면 바로 주소가 생김.

아이폰에서 열고 Safari 공유 → **홈 화면에 추가** 로 실행하면 주소창 없이 전체화면이 됩니다. 설정에서 자동 잠금을 꺼 두세요.

### C. 폰·태블릿 카메라를 센서로, 모니터를 화면으로 (2대 구성)
책상 위 폰이 관객을 찍고, 움직임 데이터(영상이 아님)만 모니터 쪽으로 보냅니다.

1. 모니터에 연결된 컴퓨터에서 B의 https 주소를 열고 **화면으로 쓰기** → 4자리 코드와 QR이 뜸.
2. 폰으로 QR을 찍으면 센서 모드로 열림 (또는 같은 주소를 열고 **센서로 쓰기** → 코드 입력).
3. **연결하고 카메라 켜기** → 폰 화면에 미리보기(파랑=사람, 빨강=움직임)와 전송 상태가 보임.
4. 모니터 쪽은 연결되는 순간 데모가 사라지고 센서 데이터로 그려집니다. `F`로 전체화면.

조건과 팁
- 두 기기 모두 인터넷 연결 필요 (연결 중계용). 같은 와이파이면 가장 안정적입니다.
- 연결이 끊기면 모니터는 자동으로 데모로 돌아가고 같은 코드로 다시 받을 수 있어요.
- 중계 서버가 안 되는 날을 대비해 **대신 이 컴퓨터 카메라 쓰기**(웹캠/USB 카메라)가 폴백입니다.

## 전시 세팅 팁
- **감지 방식**(설정): 기본은 **움직이는 것만** 감지해서 배경이 드러나지 않습니다. 정지해 있는 사람까지 실루엣으로 잡고 싶으면 **사람 실루엣(배경 분리)** 로 바꾸고, 카메라를 고정한 뒤 앞을 비우고 **배경 다시 잡기**를 누르세요.
- **배경 다시 잡기**(`B` 키 / 설정 버튼): 카메라 앞을 비운 상태에서 한 번 눌러 두면 실루엣이 깨끗해집니다. 조명이 바뀌면 다시 누르세요.
- 카메라는 고정하고, 관객 뒤 배경이 단순할수록 좋습니다. 역광은 피하세요.
- 민감도(설정): 멀리서 작은 움직임도 잡으려면 올리고, 노이즈가 튀면 내리세요.
- 자동 모드 전환(20/45/90초)을 켜 두면 사람이 없어도 화면이 계속 바뀝니다.
- 설정은 브라우저에 저장되므로 한 번 맞춰 두면 다음에 열 때 유지됩니다.
