# 숭의여자중학교 동아리 전시회 — 움직임 반응형 미디어아트 웹앱 (Gyeol)

카메라 앞의 움직임을 데이터(움직임 에너지·방향·사람 실루엣)로 바꿔, 그 데이터로 화면의 **도형·점·기호·글자**를 변형시키는 전시용 웹앱입니다.
파일 하나(`index.html`)로 동작하고, 카메라 영상은 기기 밖으로 나가지 않습니다.

## 모드 (키보드 단축키 또는 화면 좌우 스와이프)

| 키 | 이름 | 내용 |
|---|---|---|
| `1` | 시선 | 차가운 바닥 위 한색 실루엣. 카메라를 가만히 바라보는 사람의 실루엣만 천천히 따뜻한 색으로 물들고, 시선이 떠나면 식는다 |
| `2` | 도형 | 격자 위 기본 도형들이 제자리에서 피어나고 사라지며 사람을 그린다. 움직이는 곳은 도형이 바뀐다 |
| `3` | 점 | 화면 가득 흩뿌려진 점들 중 사람이 선 자리의 점만 제자리에서 차오르고, 떠나면 천천히 스러진다 |
| `4` | 도트 | 정사각 격자 위 둥근 점의 크기로 사람을 찍는 도트 매트릭스. 움직인 자리에는 작은 점이 잠시 남는다 |
| `5` | 색점 | 노란 단색 배경 위에 사람만 동그라미 격자로 찍힌다. 동그라미마다 그 자리의 실제 색을 담는다 |
| `6` | 망점 | 흰 바탕에 하늘색 망점 한 가지 잉크. 사람은 번진 덩어리로 찍히고, 망점은 가장자리에서 가장 크며 안쪽으로 갈수록 자연스럽게 작아진다. 몸이 두껍고 밝은 곳일수록 안이 더 하얗게 비어 사람마다 다르게 찍힌다 |
| `7` | 픽셀 | 실루엣이 크고 작은 파란 블록과 점으로 조립된다. 블록은 제자리에서 자라나고 줄어들며, 움직이는 곳은 무늬가 바뀐다 |
| `8` | 파동 | 움직이는 속도만큼 실루엣이 물결처럼 일렁이고, 멈추면 다시 또렷한 사람이 된다 |
| `9` | 문자 | 글자마다 잰 잉크 양으로 명암을, 윤곽은 방향에 맞는 선 기호로 그리는 문자 초상 |
| `0` | 말씀 | 화면 가득 흐르는 성경 구절. 사람이 들어오면 그 모양대로 글자가 비켜서 몸 뒤로 흘러가고, 떠나면 다시 메워져 흐른다 |
| `-` | 스케치 | 윤곽을 따라가는 연필선과 가장자리로 갈수록 진해지는 해칭 |
| `=` | 궤도 | 사람 한 명당 동선 하나. 얼굴로 같은 사람을 이어 그리고, 정해진 시간이 지나면 사라지며, 겹친 곳은 진하다 |
| `[` | 등고선 | 사람이 선 자리가 언덕처럼 솟고, 화면 전체가 지도의 등고선처럼 그 주위를 감싸 흐른다 |
| `]` | 유리 | 젖빛 유리 너머의 사람들. 유리 바로 앞까지 다가온 사람만 또렷하고 짙으며, 조금만 멀어져도 옅게 번진다 |
| `\` | 열화상 | 열화상 카메라처럼 사람은 따뜻하게, 공간은 차갑게. 머리와 손, 몸의 중심이 가장 뜨겁게 하얘진다. 차분한 남색·청록·호박·산호 색조 |
| `;` | 인식 | 실제 화면 없이, 여러 겹으로 따라 그린 윤곽선과 상자로 사람·머리·몸통·팔·다리·얼굴을 구분해 읽는 관찰 화면. 얼굴은 기억한다 |
| `'` | 시 | 앞에 가만히 서 있으면 그 사람의 실루엣을 보고 Claude가 짧은 시를 쓴다. 시는 몸의 윤곽을 따라 흐르고, 다리 사이와 바깥으로 흘러나온다 |
| `,` | 아우라 | 가까이 다가오면 사람이 열화상처럼 주황빛 아우라로 피어난다. 인증샷용 |
| `.` | 쌓기 | 앞에 3초 멈춰 서면 그 모습이 조각이 되어 왼쪽으로 옮겨져 떨어지고, 물리 법칙대로 구르며 쌓인다. 새로고침 전까지 모두 남는다 |
| `/` | 피하기 | 양옆과 위에서 날아오는 빛을 몸으로 피하는 게임. 앞에 서면 3초 뒤 시작하고, 함께 세 번 맞으면 끝. 버틴 시간이 기록되고 오늘의 순위는 새로고침 전까지 남는다 |


실제 카메라 영상은 어느 모드에서도 그대로 보이지 않습니다. 색점은 색만, 열화상은 공간의 밝기만 뽑아 쓰고, 나머지는 모두 실루엣·데이터로만 그립니다. 팔레트 6종(흰/밤/먹/네온/노을/바다): 하단 색 점 또는 `P` 키, 위아래 스와이프.

### 시 모드와 Claude
- 설정 → **시 (Claude 연결)** 에 Claude API 키를 넣으면 Claude Opus 5.5가 시를 씁니다. 키는 그 기기 브라우저에만 저장되고, 코드나 저장소에는 들어가지 않습니다.
- 보내는 것은 **실루엣 모양(흰 바탕 검은 형태)과 측정값**(서 있던 시간, 거리, 팔 위치, 사람 수, 시간대)뿐입니다. 사진·얼굴은 보내지 않습니다.
- 키가 없거나 인터넷이 안 되면 미리 준비된 시 10편 가운데 측정값에 맞는 것을 고릅니다.
- 거절 응답에 대비해 서버 측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다.

### 피하기 (게임)
- 앞에 서면 3·2·1 뒤 시작합니다. 빛 구슬이 양옆에서 서 있는 사람 쪽으로 날아오고(나오기 전 가장자리에 미리 빛남), 12초가 지나면 위에서도 떨어집니다. 시간이 갈수록 빨라지고 많아집니다.
- 앞에 선 사람 모두가 목숨 3개를 함께 씁니다. 버틴 시간이 점수이고, **오늘의 순위**(상위 3개)는 새로고침 전까지 남습니다.
- 끝나고도 계속 서 있으면 5초 뒤 다시 시작하고, 아무도 없으면 대기 화면으로 돌아갑니다.
- 자동 전환을 켜 두어도 게임 중(그리고 시를 쓰는 중, 쌓기 조각이 옮겨지는 중)에는 다음 모드로 넘어가지 않습니다.

### 필터 켜고 끄기
- 설정 → **필터 켜고 끄기**에서 필터마다 스위치로 끄고 켤 수 있습니다. 끈 필터는 아래 막대, 자동 전환, 화면 밀기, 키보드에서 모두 빠지고, 다시 켜면 돌아옵니다.
- 설정은 그 기기 브라우저에 저장되어 다음에 열어도 유지됩니다. **모든 필터 켜기**로 한 번에 되돌릴 수 있고, 하나 이상은 늘 켜져 있어야 합니다.

### 전시 제목
- 화면 왼쪽 위에 학교 로고와 **숭의여자중학교 동아리 전시회**가 늘 표시됩니다. 바탕이 밝으면 짙은 글씨(학교명은 학교 빨강), 어두우면 흰 글씨로 저절로 바뀝니다.
- 설정 → **전시 제목**에서 문구를 바꿀 수 있고, 비우면 숨겨집니다.

### 말씀 모드
- 기본 구절은 **개역한글** 본문(저작권 보호 기간이 끝난 번역)으로 넣었습니다. 전시 전에 실제 성경과 한 번 대조해 주세요.
- 설정 → **말씀**에서 한 줄에 한 구절씩 바꿀 수 있습니다. 출처는 줄 끝 괄호에: `여호와는 나의 목자시니 내가 부족함이 없으리로다 (시편 23:1)`
- 글자 크기는 줄이지 않고, 사람 몸만큼 줄이 갈라져 옆으로 비켜섭니다. 화면 가운데 사람이 서면 양쪽으로 갈라집니다.

### 쌓기 모드
- 적당한 거리(몸이 화면 높이의 40% 이상)에서 3초 동안 멈추면 실루엣이 아래부터 색으로 차오르고, 다 차면 조각이 되어 왼쪽 위로 옮겨진 뒤 떨어집니다. 조각은 물리 엔진(Matter.js, 파일 안에 포함)으로 구르고 기대며 쌓입니다.
- 서로 닿아 있는 사람들(어깨동무, 손잡기)은 **한 조각**으로 찍히고 "3명이 함께 쌓였어요"처럼 셉니다.
- 쌓인 조각은 **새로고침하기 전까지** 다른 모드로 바꾸거나 자동 전환이 돌아도 그대로 남습니다. 더미가 위에 닿으면 전체가 조용히 작아져 자리를 만듭니다.

### 인식 모델 (모두 기기 안에서 실행, 인터넷이 될 때 자동으로 받음)
- **사람 분할**: 사람 영역을 픽셀 단위로 잘라 모든 모드의 형태로 씀
- **자세**: 사람마다 뼈대를 읽어 한 명 한 명을 구분 (유리·시선·궤도·인식·시·아우라·열화상·쌓기)
- **얼굴**: 얼굴 위치와, 같은 사람이 다시 왔는지 대략 기억 (궤도·시선·인식·시). 얼굴 정보는 메모리에만 있고 저장되지 않으며 새로고침하면 지워짐
- 모델을 못 받으면 움직임 기반 방식으로 자동 전환

## 실행 방법 세 가지

### A. 노트북·태블릿 한 대로 (가장 간단)
1. `index.html`을 Chrome(또는 Edge)에서 열기 — 더블클릭으로 열어도 카메라가 됩니다.
2. **이 기기로 바로 시작** → 카메라 허용.
3. `F` 전체화면, `H` 메뉴 숨기기. 메뉴는 4초 뒤 자동으로 사라지고, 화면을 건드리면 다시 나옵니다.

### B. 아이폰·아이패드로 (HTTPS 주소 필요)
iOS Safari는 `https://` 주소에서만 카메라를 켜 줍니다. 파일을 한 번만 올려두면 됩니다.

- **GitHub Pages**: 새 저장소 → `index.html` 업로드 → Settings → Pages → Branch: main → 저장. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열림.
- **Netlify Drop**: https://app.netlify.com/drop 에 `index.html`이 든 폴더를 끌어다 놓으면 바로 주소가 생김.

아이폰에서 열고 Safari 공유 → **홈 화면에 추가** 로 실행하면 주소창 없이 전체화면이 됩니다. 설정에서 자동 잠금을 꺼 두세요.

### C. 폰·태블릿 카메라를 센서로, 모니터를 화면으로 (2대 구성)
책상 위 폰이 관객을 찍고, 움직임 데이터(영상이 아님)만 모니터 쪽으로 보냅니다.

1. 모니터에 연결된 컴퓨터에서 B의 https 주소를 열고 **화면으로 쓰기** → 4자리 코드와 QR이 뜸.
2. 폰으로 QR을 찍으면 센서 모드로 열림 (또는 같은 주소를 열고 **센서로 쓰기** → 코드 입력).
3. **연결하고 카메라 켜기** → 폰 화면에 미리보기(파랑=사람, 빨강=움직임)와 전송 상태가 보임.
4. 모니터 쪽은 연결되는 순간 데모가 사라지고 센서 데이터로 그려집니다. `F`로 전체화면.

조건과 팁
- 두 기기 모두 인터넷 연결 필요 (연결 중계용). 같은 와이파이면 가장 안정적입니다.
- 연결이 끊기면 모니터는 자동으로 데모로 돌아가고 같은 코드로 다시 받을 수 있어요.
- 중계 서버가 안 되는 날을 대비해 **대신 이 컴퓨터 카메라 쓰기**(웹캠/USB 카메라)가 폴백입니다.

## 전시 세팅 팁
- **사람 분할 모델(자동)**: 카메라를 켜면 인터넷이 되는 경우 사람 분할 모델(약 3MB, MediaPipe)을 자동으로 불러옵니다. 뜨면 화면 하단 상태에 `· 분할`이 붙고, 사람 영역이 픽셀 단위로 잡혀 정지해 있어도 꽉 찬 형태가 됩니다. 못 받으면 움직임 기반 방식으로 돌아갑니다.
- **감지 방식**(설정): 기본은 **움직이는 것만** 감지해서 배경이 드러나지 않습니다. 정지해 있는 사람까지 실루엣으로 잡고 싶으면 **사람 실루엣(배경 분리)** 로 바꾸고, 카메라를 고정한 뒤 앞을 비우고 **배경 다시 잡기**를 누르세요.
- **배경 다시 잡기**(`B` 키 / 설정 버튼): 카메라 앞을 비운 상태에서 한 번 눌러 두면 실루엣이 깨끗해집니다. 조명이 바뀌면 다시 누르세요.
- 카메라는 고정하고, 관객 뒤 배경이 단순할수록 좋습니다. 역광은 피하세요.
- 실제 카메라 영상은 어떤 모드에서도 그대로 나오지 않습니다. 모두 실루엣·데이터로만 표현됩니다.
- 설정은 세 가지만: **반응**(차분/보통/활발), **흔적**(짧게/보통/길게), **감지**(움직임만/사람 전체). 기본값이 최적값이고, 멀리서 작은 움직임까지 잡으려면 반응을 '활발'로.
- 자동 모드 전환(20/45/90초)을 켜 두면 사람이 없어도 화면이 계속 바뀝니다.
- 설정은 브라우저에 저장되므로 한 번 맞춰 두면 다음에 열 때 유지됩니다.

## 단축키
위 표의 키로 모드 전환 · `← →` 모드 · `P` 팔레트 · `F` 전체화면 · `H` 메뉴 숨기기/보이기 · `C` 지우기(스케치·궤도 · 쌓기는 새로고침해야만 지워짐) · `M` 좌우 반전 · `B` 배경 다시 잡기
